Features

Everything a QR code needs, nothing it doesn't.

Built for people who need a clean code fast — marketers, event organizers, shop owners, or anyone sharing a Wi-Fi password without shouting it across the room.

Live preview

Your code updates as you type — no "generate" button to hunt for, no page reloads.

Six code types

Links, plain text, Wi-Fi logins, email drafts, phone numbers, and contact cards.

Custom colors

Match your brand with preset palettes or pick exact foreground and background colors.

PNG & SVG export

Download a crisp raster for slides and social, or a vector for print at any size.

Adjustable error correction

Choose how much damage or overlay a code can take before it stops scanning.

Private by design

Codes are built entirely in your browser. Nothing you type is uploaded or stored.
